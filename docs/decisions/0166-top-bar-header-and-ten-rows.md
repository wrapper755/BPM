# ADR-0166. 위 막대를 한 결로 맞추고, 표 머리는 붙어 서고, 목록은 10줄씩 — 맨 앞·맨 뒤 단추

| --- | --- |
| 상태 | 일부 대체됨([ADR-0167](0167-page-size-and-pages-on-the-server.md) — §1 글자 13 → 14, §3 10줄 → 줄 수 고르기·기본 20) |
| 날짜 | 2026-11-20 |
| 관련 | 화면 CON-00 [A]·[B], [ADR-0165](0165-lists-filter-as-you-go-and-page.md) §4(20줄 — **이 결정이 10줄로 바꾼다**), [ADR-0164](0164-neutral-pro.md)(앱 타일·위 막대), [ADR-0152](0152-console-chrome-is-one-top-bar.md) |

## 배경

결재함(CON-04)을 보고 사용자가 셋을 짚었다.

1. **위 막대의 아이콘과 제목이 따로 논다** — 앱 타일 28에 「BPM」 16, 묶음 13, 오른쪽은 배지 12·계정 13·단추 14로 글자 크기가 넷이었고 단추만 높이가 달라 한 줄에 서지 않았다. 마크와 첫 묶음 사이도 좁았다.
2. **표 머리가 약하다** — 흰 바탕에 12px 옅은 글자라 줄과 갈리지 않았고, `sticky`가 `overflow-auto` 틀 안에 있어서 **페이지를 내리면 머리가 그냥 사라졌다**.
3. **한 쪽 20줄이 길다** — 결재함은 줄마다 두 줄로 접혀 20줄이면 화면 두 장이다. 마지막 쪽으로 한 번에 갈 길도 없었다.

## 결정

1. **위 막대의 글자는 13(`body-sm`) 한 크기다** — 묶음·배지·계정·단추가 같다. 앱 타일은 **24**(`sm`)로 낮춰 「BPM」(16, 굵게)의 글자 높이와 맞추고, 마크와 첫 묶음 사이는 24(`space-6`)다. 오른쪽은 **한 묶음**이다 — 배지·계정, 옅은 세로 선, 「새로 고침」·「로그아웃」(높이 32)이 붙어 선다.
2. **표 머리는 옅은 회색 면(`bg-subtle`)에 13 굵게(`text-secondary`)** 이고 칸 여백은 본문 칸과 같다. 표 틀은 가로로 넘칠 때만 스크롤 틀이 된다 — 넘치지 않으면 `overflow-x: clip`이라 **머리가 위 막대 바로 아래에 붙어 선다**. 넘치는 표(좁은 창의 넓은 표)는 가로 스크롤이 먼저라 머리가 틀 안에 남는다 — 한 상자가 가로 스크롤과 페이지 기준 고정을 함께 할 수 없다(CSS).
3. **목록은 10줄씩이다**(ADR-0165 §4를 대체한다). 앞·뒤 바깥에 **「맨 앞」·「맨 뒤」**(`ChevronsLeft`·`ChevronsRight`)를 두고 끝에서는 끈다.

## 결과

- 열 줄이면 결재함 한 쪽이 한 화면에 든다. 줄이 많은 목록은 쪽 단추를 더 누른다 — 「맨 뒤」가 그 수고를 줄인다.
- 표 머리는 모든 목록이 따라온다(`DataTable` 하나).
