# ADR-0132. 데스크톱 아이콘은 Lucide SVG 대신 우리가 그린 한 색 마스크(PNG)를 쓴다

| 항목 | 값 |
| --- | --- |
| 상태 | 수락 |
| 날짜 | 2026-11-05 |
| 관련 | 스파이크 `spikes/s12-studio-icons`, [ADR-0017](0017-web-nextjs-design-system.md)(아이콘 줄 중 데스크톱 부분), 스타일 가이드 §6 |

## 배경

Studio의 아이콘은 도구 모음 7개와 「변수」 탭 단추 3개뿐이었고, 모두 Lucide SVG를 옮겨 둔 것이었다.
탐색기 줄·대화상자의 보조 단추(더하기·삭제·위로·새로 고침 …)·창 아이콘은 비어 있었다.
아이콘을 Studio 전체로 넓히면서 한 벌을 우리 손으로 다시 그려 같은 결로 맞추기로 했다.
그림은 이미지 생성 모델(Gemini `gemini-3.1-flash-image`)로 뽑고 사람이 시안 넷 중 하나(「선」)를 골랐다.

## 선택지

| 선택지 | 장점 | 단점 |
| --- | --- | --- |
| A. Lucide SVG를 계속 쓰고 이름만 더한다 | 웹과 같은 벌, 벡터 | 다시 그리지 않는다 — 요청과 다르다 |
| B. 생성한 그림을 색 있는 PNG로 둔다 | 간단 | 밝게·어둡게·강조색 바탕마다 따로 있어야 하고 토큰 밖의 색이 들어온다 |
| C. 생성한 그림을 **한 색 마스크(검정 + 알파) PNG**로 두고 Qt가 토큰 색으로 칠한다 | 지금 `icon(이름, 색)`과 같은 쓰임, 테마가 바뀌면 다시 칠하면 된다, 색은 토큰뿐 | 벡터가 아니다 — 128px 원본을 20·40으로 줄인다 |

## 결정

**C를 고른다.** 데스크톱(Qt) 아이콘은 `shared/qt`의 테마 폴더에 `icon-<이름>.png`(128×128, 검정 + 알파)로 두고
`bpm.qt.theme.icon(이름, 색)`이 알파 모양대로 `색`을 칠한다(20과 고해상도용 40). 색은 늘 팔레트(토큰)에서 온다.

- 생성·마스크 만들기는 `spikes/s12-studio-icons/`(제품 코드가 import하지 않는다). 흰 바탕 검정 그림 → 밝기를 알파로 →
  그림 둘레를 잘라 8% 여백 → 128px. 짝(실행 취소·다시 실행, 위·아래 화살표)은 한쪽을 뒤집어 짓는다.
- 창 아이콘(`app`)은 BPM 흐름 마크를 판에 새긴 그림이고 `primary`로 칠한다.
- 웹은 그대로 `lucide-react`다. Qt의 Lucide SVG와 그 사용 허가 파일은 걷는다.

## 결과

- 이 결정으로 쉬워지는 것: 아이콘을 더할 때 이름 하나와 프롬프트 한 줄이면 된다. 밝게·어둡게는 칠할 색만 바뀐다.
- 어려워지거나 포기하는 것: 웹과 데스크톱의 아이콘 모양이 같은 벌이 아니다. 아주 큰 크기(128 초과)에서는 흐려진다.
  생성 모델은 같은 프롬프트에도 다른 그림을 주므로 한 장을 다시 뽑으면 나머지와 결이 어긋날 수 있다 — 판으로 나란히 보고 고른다.
- 다시 볼 조건: 128px보다 큰 아이콘이 필요하거나, 웹과 데스크톱을 한 벌로 맞추자는 요구가 생기면.
