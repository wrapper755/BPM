# ADR-0179. 설정에 적을 Center 주소는 일꾼의 토큰 창에 둔다

| 항목 | 값 |
| --- | --- |
| 상태 | 수락 |
| 날짜 | 2026-11-20 |
| 관련 | 화면 CON-17·CON-00, [ADR-0149](0149-console-menu-follows-the-work.md) §6(**자리를 대체한다**) |

## 배경

ADR-0149 §6은 「일꾼 설정에 적을 Center 주소」를 CON-17 제목 오른쪽에 두었다. 그 주소를 적는 사람은 일꾼을 띄우는
사람 하나이고 한 번인데, 목록을 보는 사람 모두에게 늘 서 있었다. 사용자가 2026-11-20에 「사용자에게 보일 필요가 없다」고 했다.

## 선택지

| 선택지 | 장점 | 단점 |
| --- | --- | --- |
| A. **토큰을 보이는 창에 둔다**(「새 일꾼...」·「토큰 새로 발급...」) | 적을 두 값(토큰·주소)이 한 자리에 선다. 목록이 조용하다 | 토큰 없이 주소만 다시 보려면 토큰을 새로 받아야 한다 |
| B. 아예 걷는다 | 가장 조용하다 | 토큰 창이 「Center 토큰에 넣으세요」라고만 말하고 주소는 어디에도 없게 된다(ADR-0149가 고친 것으로 돌아간다) |

## 결정

**A다.** 주소 한 줄과 「복사」를 토큰 창의 토큰 아래로 옮기고 CON-17 머리에서 걷는다. 글·동작(「복사」가 막히면 글자를
골라 복사하라는 말, `BPM_CONSOLE__CENTER_PUBLIC_URL`)은 그대로다.

## 결과

- 쉬워지는 것: 일꾼을 띄우는 사람이 한 창에서 두 값을 받는다. 목록 머리에는 「새 일꾼...」 하나가 선다.
- 어려워지거나 포기하는 것: 주소만 다시 보는 길이 없다 — 주소는 배포마다 정해진 값이라 compose `.env`에도 있다.
- 다시 볼 조건: 토큰 없이 주소를 적어야 하는 일(예: 다른 종류의 일꾼)이 생기면.
