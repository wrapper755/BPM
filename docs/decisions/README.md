# 결정 기록 (ADR)

결정 하나당 파일 하나. 형식은 [template.md](template.md).

- 번호는 순서대로 붙이고 재사용하지 않는다.
- 수락된 ADR은 고치지 않는다. 뒤집을 때는 새 ADR을 쓰고 옛 것의 상태를 `대체됨(ADR-XXXX)`으로 바꾼다.
- 스파이크가 끝나면 결론이 "안 된다"여도 ADR을 쓴다.
- "제안" 상태를 "수락"으로 바꿀 때는 이 표와 해당 파일의 상태 칸을 함께 고친다.
