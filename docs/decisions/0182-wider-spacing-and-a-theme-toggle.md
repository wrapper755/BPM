# ADR-0182. 여백을 한 단계 넓히고, 밝게·어둡게를 위 막대에서 고른다

| 항목 | 값 |
| --- | --- |
| 상태 | 수락 |
| 날짜 | 2026-11-20 |
| 관련 | `docs/07-style-guide.md`, `design/tokens.json`, 화면 CON-00, [ADR-0164](0164-neutral-pro.md)(중립 프로 — 그대로 산다, 바탕 값만 다듬는다), [ADR-0173](0173-top-bar-right-is-icons.md)(위 막대 오른쪽은 아이콘 — 하나 더한다) |

## 배경

사용자가 콘솔을 「SaaS 대시보드처럼」 — **여백을 넓히고, 모던한 색, 다크모드 토글** — 해 달라고 했다.
짚어 보니 어두운 색은 토큰에 이미 있고 운영체제 설정(`prefers-color-scheme`)을 따라 바뀌지만 **콘솔에서 고를 길이 없었다**. 어두운 바탕은 남색 기운이 섞인 값(`#0B0D12`)이라 밝은 쪽의 「차가운 회색」과 결이 달랐다. 표 줄 44·본문 여백 16→24→32는 촘촘한 편이었다.

## 선택지

| 선택지 | 장점 | 단점 |
| --- | --- | --- |
| **남보라 유지·다듬기** — 브랜드 색 그대로, 바탕·선만 정리하고 어둡게는 무채색(zinc) | ADR-0164를 그대로 산다. 마크·로그인이 바뀌지 않는다 | 한눈에 달라 보이는 폭은 작다 |
| 선명한 파랑 | 흔한 SaaS 인상 | 브랜드 색이 바뀐다(마크·탭 아이콘까지) |
| 보라-틸 그라데이션 | 가장 「홍보 페이지」 같다 | D2(그라데이션을 쓰지 않는다)와 부딪친다. 하루 종일 보는 표에 시끄럽다 |

여백은 「한 단계」와 「두 단계」, 토글 자리는 「위 막대 아이콘」과 「계정 메뉴 안」을 보였다. 사용자는 **남보라 유지·한 단계·위 막대 아이콘**을 골랐다.

## 결정

1. **색은 ADR-0164 그대로, 바탕만 다듬는다** — 밝게: 바탕 `#F8FAFC`, 옅은 면 `#F1F5F9`, 선 `#E4E7EC`. 어둡게: **무채색(zinc)** — 바탕 `#09090B`, 면 `#111113`, 옅은 면 `#18181B`, 선 `#27272A`, 글자 `#FAFAFA`/`#D4D4D8`/`#A1A1AA`. 강조색·상태 색은 바꾸지 않는다.
2. **여백을 한 단계 넓힌다** — 본문 여백 20→32→40(좁은 화면→`md`→`lg`), 위아래 24→32→40. 묶음 카드 안쪽 16·20→20·24, 거르기 카드 16→20, 제목 아래 24→32. 표 줄 `row.default` 44→**48**, `row.compact` 36→**40**. 위 막대 안쪽은 본문과 같은 여백을 따른다(ADR-0164 §4).
3. **밝게·어둡게는 위 막대의 아이콘 하나다** — ↻ 「새로 고침」 앞에 선다. 누를 때마다 **시스템 → 밝게 → 어둡게** 차례로 돌고, 아이콘(모니터·해·달)과 말풍선이 지금 값을 말한다. 고른 값은 **그 브라우저에만** 남는다(`localStorage` — 계정 설정이 아니다). 처음 그릴 때 깜빡이지 않게 `<head>`의 짧은 스크립트가 그리기 전에 `data-theme`을 단다.
4. 로그인 화면은 토글이 없고 그 브라우저에서 고른 값(없으면 시스템)을 따른다.

## 결과

- 쉬워지는 것: 밤에 운영하는 사람이 운영체제 설정을 건드리지 않고 어둡게 쓴다. 어둡게가 밝게와 같은 「무채색 + 남보라 하나」로 읽힌다.
- 어려워지거나 포기하는 것: 한 화면에 보이는 표 줄이 열에 하나쯤 준다. 고른 값이 계정을 따라다니지 않는다(다른 브라우저에서는 다시 고른다).
- 다시 볼 조건: 「줄이 너무 적게 보인다」는 말이 나오면 표만 `compact`로 돌린다(여백은 두고). 테마를 계정에 묶어 달라면 C5 계정에 칸을 더한다.
- 서비스 앱 콘솔은 범위 밖이다 — 같은 토큰을 쓰므로 색·줄 높이는 따라가고 토글은 없다.
