# ADR-0169. 「공통 패키지」는 「저작」 묶음에 둔다

| 항목 | 값 |
| --- | --- |
| 상태 | 수락 |
| 날짜 | 2026-11-20 |
| 관련 | 화면 CON-00 [M]·CON-06·CON-15·CON-20, [ADR-0151](0151-console-follows-the-lifecycle.md)(묶음 여섯 — **줄 하나를 옮긴다**) |

## 배경

ADR-0151은 「배포」 묶음에 「배포」(CON-15)와 「공통 패키지」(CON-06)를 두었다. 사용자가 「공통 패키지가 의미상 맞지 않는다 — 있어야 할 자리가 아니다」라고 했다.

「배포」는 **승인된 판을 실행기에 올리고 철회하는 일**이다. 공통 패키지는 여러 BPM 프로세스가 함께 쓰는 도구·정의 묶음이고, 사람이 그것을 만나는 때는 **그림을 그릴 때**다 — 작업공간이 공통 패키지를 들여 쓰고(C17 설치), 지은 것이 공통 패키지가 된다(CON-20 「짓기」). 공통 패키지는 배포되지 않는다 — 그것을 쓰는 BPM 프로세스가 배포된다.

## 결정

1. 「공통 패키지」를 **「저작」 묶음**으로 옮긴다 — 「저작」은 「작업공간」·「공통 패키지」 두 줄이 되어 펼친다.
2. 「배포」 묶음은 줄이 하나라 **펼치지 않고 바로 간다**(「대시보드」와 같은 결, ADR-0152).
3. 묶음 여섯과 차례(대시보드 › 저작 › 배포 › 운영 › 연결 › 권한·조직)는 그대로다.

## 결과

- 「저작」을 누르면 펼쳐진다 — 전에는 바로 작업공간으로 갔다.
- CON-06의 주소(`/packages`)는 그대로다. 지금 자리 줄은 「저작 › 공통 패키지」가 된다.
