# ADR-0170. 펼친 메뉴의 한 줄 설명은 넓은 화면에서 말풍선으로 — 그리고 `tonal`을 조금 짙게

| 항목 | 값 |
| --- | --- |
| 상태 | 수락 |
| 날짜 | 2026-11-20 |
| 관련 | 화면 CON-00 [M], [ADR-0152](0152-console-chrome-is-one-top-bar.md) §2(줄마다 한 줄 설명 — **넓은 화면만 바꾼다**), [ADR-0162](0162-usability-heuristics-review.md) U20(말풍선은 덧붙임뿐), [ADR-0168](0168-list-header-buttons-are-tonal.md)(`tonal` 면 — **짙기를 바꾼다**) |

## 배경

사용자가 둘을 말했다.

1. 펼친 메뉴의 줄마다 붙은 **한 줄 설명**(「회사·부서·직원과 업무 자리」…)을 **말풍선으로** 두기를 바랐다 — 줄이 두 겹이라 메뉴가 길고 이름이 묻혔다.
2. 옅게 바꾼 「새 …」 단추(`tonal`)가 **조금만 더 짙었으면** 했다 — `primary.subtle`(#EEF2FF)은 흰 표·옅은 회색 바탕 위에서 단추로 잘 안 보였다.

U20(ADR-0162)은 「설명을 말풍선에만 두지 않는다 — 휴대폰에서 뜨지 않는다」이다.

## 결정

1. **넓은 화면(1024~)의 펼친 메뉴는 이름만** 보이고 한 줄 설명은 그 줄의 **말풍선**(`title`)이다. 보조기기에는 설명을 그대로 읽힌다(가린 글자).
2. **좁은 화면(1024 아래)의 한 장 메뉴는 설명을 글로 둔다** — 말풍선이 뜨지 않는 자리라서다(U20). 그래서 설명이 말풍선에**만** 있는 자리는 없다.
3. **`tonal`의 면은 `primary`를 12% 섞은 것**이고 누르면 20%다(ADR-0168은 `primary.subtle` 그대로, 누르면 8%). 글자는 `primary` 그대로 — 대비는 4.5:1을 넘는다.

## 결과

- 넓은 화면의 펼친 메뉴가 절반 높이로 준다. 처음 쓰는 사람은 마우스를 올려야 설명을 본다.
- 「새 …」 단추가 입구로 보이되 칠한 단추보다는 조용하다.
