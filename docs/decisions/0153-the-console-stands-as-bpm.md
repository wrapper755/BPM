# ADR-0153. 콘솔은 제 이름 BPM으로 선다 — 로그인과 탭 제목에서 INNONOW를 걷는다

| 항목 | 값 |
| --- | --- |
| 상태 | 수락 |
| 날짜 | 2026-11-15 |
| 관련 | 화면 CON-00(로그인·틀), [ADR-0120](0120-innonow-brand-on-login.md)(**이 결정이 대체한다**), [ADR-0118](0118-no-product-name-on-screens.md)(마크 — 「이름을 쓰지 않는다」의 다시 볼 조건이 찼다), [ADR-0130](0130-rename-to-bpm.md)·[ADR-0126](0126-operator-facing-names-say-bpm.md)(사람에게 보이는 이름은 대문자 BPM) |

## 배경

[ADR-0120](0120-innonow-brand-on-login.md)은 2026-10-31에 로그인 머리 띠와 브라우저 탭 제목을 **INNONOW**(이 콘솔을 쓰는
쪽의 브랜드)로 두었다. 그때는 제품 이름이 미정이었고 화면에 쓸 이름이 **저장소 이름(Chaeksas)뿐**이라
([ADR-0118](0118-no-product-name-on-screens.md)) 빈자리를 브랜드가 채운 것이다.

그 뒤 [ADR-0130](0130-rename-to-bpm.md)·[ADR-0126](0126-operator-facing-names-say-bpm.md)으로 **사람에게 보이는 이름이
대문자 BPM**으로 정해졌다. 2026-11-15 사용자가 「INNONOW는 빼 주고 BPM만, 로그인 페이지도 마찬가지로」라고 했다.
같은 자리에서 「BPM 아이콘이라고 하기에는 애매하다 — 잘려서」라고도 짚었다(레일 56 안에서 가로 96:28 마크가 잘렸다).

## 결정

**화면에 서는 이름은 「BPM」 하나다.**

- **브라우저 탭 제목은 모든 화면에서 「BPM」**이다 (전에는 「INNONOW — Management Transformation Center」).
- **로그인 머리 띠**의 INNONOW 로고 자리에 **BPM 흐름 마크 + 「BPM」**을 둔다. 문구 두 줄(「AI와 함께, 경영을 실행합니다.」·
  「Management Transformation in Action.」)과 배경 그림은 **그대로**다 — 브랜드 로고가 아니라 이 제품이 하는 말이다.
- **위 막대 맨 왼쪽**도 같은 **마크 + 「BPM」**이고 누르면 첫 화면이다 ([ADR-0152](0152-console-chrome-is-one-top-bar.md) §1).
  **마크 옆에 글자가 서므로 마크가 잘리지 않는다** — 가로로 긴 마크(96:28)가 가로 막대에 제 폭으로 들어간다.
- INNONOW 로고 파일 둘(`server/web/apps/center-console/public/brand/logo-innonow-{navy,ivory}.png`)을 지운다.
- **서비스 앱 관리 콘솔은 그대로다** — 거기에는 그 앱의 이름이 선다(ADR-0118).

ADR-0118의 「화면에 제품 이름을 쓰지 않는다」는 **저장소 이름(Chaeksas)을 쓰지 않는다**는 뜻이었고, 그 ADR이 적어 둔
다시 볼 조건(「제품 이름이 정해지면 마크 옆에 그 이름을 둘지 다시 본다」)이 **이제 찼다**. 마크는 그대로 쓰고 이름이 옆에 선다.

## 결과

- 쉬워지는 것: 어느 제품인지 화면이 스스로 말한다. INNONOW가 아닌 곳에 Center를 설치할 때 **고칠 것이 없다**(ADR-0120이
  「다시 볼 조건」으로 적어 둔 바로 그것이다). 로고 PNG 둘이 없어져 토큰 색을 따르지 않는 그림이 하나 줄었다.
- 어려워지거나 포기하는 것: NowView·누리집과 **같은 브랜드로 이어 보이지 않는다** — 띠의 문구만 남는다.
- 다시 볼 조건: 브랜드를 다시 세우기로 하면 **설정으로** 뺀다(로고·문구·탭 제목을 환경변수로) — 코드에 다시 적지 않는다.
