# ADR-0187. 메뉴 줄·대시보드·편집기 머리에 Lucide 아이콘을, 빈 상태에는 그린 그림을 둔다

| 항목 | 값 |
| --- | --- |
| 상태 | 수락 |
| 날짜 | 2026-11-21 |
| 관련 | 스타일 가이드 §6, CON-00 [M]·[B], CON-21, CON-20b, [ADR-0152](0152-console-chrome-is-one-top-bar.md) §2(이름 + 한 줄 설명 — 그대로. 스타일 가이드 §6이 이를 들어 적은 「메뉴 줄에는 두지 않는다」를 **이 결정이 바꾼다**), [ADR-0132](0132-desktop-icons-are-drawn-masks.md)(한 색 마스크의 결을 웹 그림에 가져온다), [ADR-0157](0157-status-colours-stay-under-the-brand.md)(가장 진한 색은 주 단추 하나 — 그대로) |

## 배경

콘솔을 제품 수준으로 다시 보며(2026-11-21) 화면이 글자만으로 서 있는 자리를 짚었다.

- 아이콘은 위 막대 오른쪽(테마·새로 고침·로그아웃)과 몇 단추에만 있다. 펼친 메뉴의 열한 줄, 대시보드 카드 여섯, 「지금 할 일」 종류 표지(실패·결재·승인), 편집기 머리의 단추 넷이 모두 글자뿐이라 훑어 찾을 때 붙잡을 모양이 없다.
- 스타일 가이드 §6은 「메뉴 줄에는 두지 않는다 — 줄은 이름과 한 줄 설명이 말한다」(ADR-0152를 들어)였다. 그때 설명은 줄 아래 글이었고 지금은 넓은 화면에서 말풍선이다(ADR-0170) — 줄에 남은 것이 이름 하나다.
- 빈 상태(결재함 비었음·프로젝트 없음 …)는 회색 글 한 줄이라 「아직 아무것도 없다」와 「읽다 말았다」가 같아 보인다.

## 선택지

| 선택지 | 장점 | 단점 |
| --- | --- | --- |
| A. 작은 아이콘·빈 상태 그림을 모두 생성 그림으로 | 한 결이다 | Lucide와 두 벌이 된다(위 막대가 이미 Lucide). 16px 그림은 선이 뭉개진다 |
| B. **작은 아이콘은 Lucide, 빈 상태처럼 큰 자리만 그린 그림** | 작은 자리는 한 벌 그대로다. 그림은 큰 자리에서만 보여 두 벌로 읽히지 않는다 | 그림을 더할 때 생성·마스크 손이 간다 |
| C. 빈 상태도 Lucide를 크게 | 손이 가장 적다 | 64px로 키운 선 아이콘은 「단추가 크다」로 읽힌다 |

그림의 결은 시안 넷(선만·선 + 회색 면·작은 정물·점선 연결)을 한 판씩 뽑아 사용자가 **점선 연결**을 골랐다(`spikes/s13-empty-states/`) — 둥근 네모와 점선이 BPMN 그림과 결이 맞고, 선만인 결은 Lucide를 키운 것과 닮았다.

## 결정

**B로 한다.**

1. **Lucide를 네 자리에 더 둔다** — 펼친 메뉴의 줄마다 이름 앞(16), 대시보드 카드 제목 앞(16), 「지금 할 일」 종류 표지 안(16), 편집기 머리 단추의 글 앞(16). **위 막대의 묶음 글자에는 두지 않는다**(여덟이 한 줄에 서야 한다). 아이콘은 **장식**이라 `aria-hidden`이고 이름은 글이 말한다. 색은 글자의 색을 따른다(`currentColor`) — 아이콘에 따로 칠하지 않는다. 메뉴 줄의 아이콘은 `text-muted`이고 고른 줄에서는 글과 같은 색이다.
2. 메뉴·화면이 **같은 대상에 같은 아이콘**을 쓴다 — 줄 「결재함」과 대시보드 카드 「기다리는 결재」와 「지금 할 일」의 「결재」는 같은 모양이다. 짝은 `components/icons.ts` 한 곳에 둔다.
3. **빈 상태 그림은 한 색 마스크 PNG**다. 생성한 판을 칸마다 잘라 **밝기를 알파로** 바꾸고(검정 + 알파, 회색 면은 반투명이 된다) `public/empty/`에 둔다. 화면은 CSS `mask-image`로 그 모양을 따서 **`text-muted` 토큰 색**으로 칠한다 — 밝게·어둡게는 칠하는 색만 바뀐다. 그림은 장식이라 읽지 않는다.
4. 그림은 여섯이다 — 결재(빈 받은 함), 프로젝트(빈 폴더), 실행(빈 타임라인), 작업 지시(빈 점검표 + 시계), 거르기에 걸린 것 없음(돋보기), 연결 없음(떨어진 플러그). **「조건에 맞는 것이 없다」는 어느 화면이든 돋보기**이고 그 밖의 빈 상태는 그 화면의 그림이다. 그림이 없는 화면은 지금처럼 글뿐이다.
5. 생성은 `spikes/s13-empty-states/`에서 하고 제품 코드가 import하지 않는다. 자르고 마스크로 바꾸는 것도 거기 있다(`cut.py`).

## 결과

- 쉬워지는 것: 메뉴와 대시보드를 모양으로 훑는다. 빈 화면이 「비었다」를 그림으로 말한다.
- 포기하는 것: 메뉴 줄이 한 칸 넓어진다. 그림은 벡터가 아니라 PNG라 아주 크게 띄우면 흐리다(지금은 96 한 크기).
- 다시 볼 조건: 아이콘 짝이 화면마다 갈라지기 시작하면(같은 대상에 다른 모양) `icons.ts`를 고치는 대신 시험으로 막는다. 그림 결을 바꾸면 여섯을 한 판에서 다시 뽑는다.
