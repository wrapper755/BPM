# ADR-0156. 되돌리기는 단축키뿐이다 — 키를 쥔 그림이 듣는다

| 항목 | 값 |
| --- | --- |
| 상태 | 수락 |
| 날짜 | 2026-11-16 |
| 관련 | 화면 CON-20b, [ADR-0143](0143-design-happens-in-the-console.md)(저작이 콘솔에서), [ADR-0152](0152-console-chrome-is-one-top-bar.md)(틀은 위 막대 하나), [ADR-0155](0155-resources-are-a-tab-in-the-explorer.md)(리소스에서 노드 만들기), [ADR-0022](0022-studio-canvas.md)·[ADR-0044](0044-canvas-drag-and-drop.md)(「한 번이 실행 취소 한 걸음」), `docs/09-gaps.md` §3-36 |

## 배경

조각 12에서 리소스로 노드를 만들다, **잘못 만든 것을 되돌릴 길이 콘솔에 하나도 없다**는 것이
드러났다(§3-36). 캔버스는 `undo()`·`redo()`를 내주고 명령 묶음도 제대로 한 걸음인데, 부르는
자리가 없었다 — 단추도, 단축키도.

고치려고 보니 §3-36에 적은 까닭이 **틀렸다**. bpmn-js의 `keyboard` 모듈은 **이미 붙어 있다**
(`Modeler`의 기본 모듈이고, diagram-js 15부터 **붙이는 자리를 고를 수 없다** — 그림 SVG에 제
손으로 붙고 `bindTo`를 주면 오류를 낸다). 듣지 않던 것은 **키를 쥔 자리** 때문이다: 그 리스너는
그림(SVG, `tabindex=0`)에 달려 있어 그림이 키를 쥐고 있을 때만 듣는데, 리소스 탭의 「+」를
누르면 키는 **그 단추**에 남는다. 그림은 요소를 눌렀을 때 스스로 키를 쥔다.

그러니 정할 것은 하나였다 — **되돌리기를 부르는 자리를 눈에 보이게 둘 것인가.**

## 선택지

| 선택지 | 장점 | 단점 |
| --- | --- | --- |
| **A. 단축키만** | 머리 띠가 늘지 않는다(ADR-0152에서 줄인 자리다). 키는 bpmn-js가 이미 쥐고 있어 **우리 코드가 거의 없다** | **눈에 보이는 길이 없다** — 모르는 사람은 되돌릴 줄 모른다. 터치만 쓰는 판에는 길이 없다 |
| B. 단축키 + 머리 띠에 단추 둘 | 보인다. 터치에서도 된다 | 머리 띠에 늘 두 칸을 쥔다. 되돌릴 것이 없을 때의 끈 단추까지 그린다 |
| C. 단축키 + 캔버스 위에 떠 있는 단추 | 그림 옆이라 가깝다 | 팔레트·상세 패널과 자리를 다툰다. 작은 화면에서 그림을 가린다 |

## 결정

**A** — 되돌리기·다시 하기는 **단축키뿐**이다. 단추를 두지 않는다.

- 키는 **bpmn-js의 것 그대로**다 — `Ctrl+Z`(macOS `Cmd+Z`)가 되돌리기, `Ctrl+Y`·`Cmd+Shift+Z`가
  다시 하기다. 우리 글로 다시 정하지 않는다.
- **창(window)에 리스너를 달지 않는다.** 달면 결정표 격자·케이스 편집기·속성 칸에서 글을 쓰다
  누른 `Ctrl+Z`가 **그림을 되돌린다**. 리스너가 그림에 달려 있어 그 걱정이 아예 없다 — 글 쓰던
  칸에서 누른 것은 그 칸의 되돌리기다.
- **바깥에서 그림을 고친 뒤에는 키를 그림에 돌려준다** — `createTask`가 끝에
  `canvas.focus()`를 부른다(리소스 탭의 「+」와 끌어다 놓기가 같은 자리다, ADR-0155). 그래서
  만든 바로 뒤에 `Ctrl+Z`가 듣는다.
- **아무도 키를 쥐지 않았으면 그림 위로 마우스를 올릴 때 되돌려 준다**(`canvas.autoFocus`) —
  쥔 자리가 있으면 빼앗지 않는다.
- 보기 모드(뷰어)는 고칠 것이 없어 해당 없다.

## 결과

- 이 결정으로 쉬워지는 것: 머리 띠가 그대로다. 같은 단추가 두 곳에 생기는 일이 없다. 단축키가
  **그림에만** 걸려 있어 「어느 되돌리기인가」를 우리가 가를 필요가 없다.
- 어려워지거나 포기하는 것: **발견할 길이 없다** — 화면 문서에 적는 것 말고는 알려 주지
  않는다. 터치만 쓰는 판에서는 되돌릴 수 없다(지우는 것은 고르고 `Delete`다).
- 다시 볼 조건: 태블릿·터치로 저작한다, 또는 사람이 「되돌릴 줄 몰랐다」고 말한다 → 머리 띠에
  단추 둘을 더한다(자리는 ADR-0152 §7의 머리 띠이고, 부를 것은 이미 있는
  `CanvasEditor.undo()`·`redo()`다).
