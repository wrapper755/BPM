# ADR-0163. BPM 흐름 마크를 굵게 하고 작은 자리에는 정사각 기호를 쓴다 — 칸 테두리는 3:1로 올린다

| 항목 | 값 |
| --- | --- |
| 상태 | 수락 |
| 날짜 | 2026-11-20 |
| 관련 | `docs/07-style-guide.md` §2-1·§6-1, `design/bpm-mark.svg`·`design/bpm-symbol.svg`, `design/tokens.json`, [ADR-0118](0118-no-product-name-on-screens.md)(BPM 흐름 마크 — **모양은 그대로 산다**), [ADR-0161](0161-soft-cards.md)(부드러운 카드) |

## 배경

사용자가 로그인 화면의 BPM 아이콘과 색을 검토해 달라고 했다. 셋이 걸렸다.

- **탭 아이콘(16px)에서 마크가 보이지 않는다** — 가로로 긴 마크(96×28)를 정사각에 그대로 넣어 높이 5px쯤의 실선이 된다.
- **선이 가늘다** — 선 1.8은 위 막대(20px)에서 1.3px쯤이라 시작 원·연결선이 흐려지고 채운 네모만 남는다(「—■—」).
- **입력칸 테두리(`border.strong`)가 3:1에 못 미친다** — 밝게 2.64:1, 어둡게 2.42:1. WCAG 1.4.11(UI 경계 3:1)을 어긴다. `gen_tokens.py`가 경고로만 내던 것이다.

## 선택지

| 선택지 | 장점 | 단점 |
| --- | --- | --- |
| A 선만 굵게 | 모양이 그대로다 | 탭 아이콘은 여전히 실선이다 |
| **B 굵게 + 작은 자리용 정사각 기호** (사용자가 골랐다) | 탭 아이콘에서도 알아본다 | 그림이 둘이 된다 |

## 결정

1. **마크의 선을 1.8 → 2.8로** 굵게 하고 도형을 조금 키운다. 시작 → 태스크 → 배타 게이트웨이 → 끝, 색 `primary` 하나라는 **모양은 그대로**다(ADR-0118).
2. **정사각 기호** `design/bpm-symbol.svg` — 마크의 가운데 두 도형(**태스크 → 배타 게이트웨이**)만 남긴 것. **마크가 들어갈 폭이 없는 자리**(브라우저 탭 아이콘)에만 쓴다. 웹 구성요소는 `BpmSymbol`이고 마크와 같이 `gen_tokens.py`가 짓는다(원본은 둘 다 `currentColor`뿐).
3. **`border.strong`을 3:1 위로** — 밝게 `#8C877D`(3.6:1), 어둡게 `#77736B`(3.7:1). **경고가 아니라 막는 검사**로 올린다 — 다시 내려가면 생성이 멈춘다.

## 결과

- 쉬워지는 것: 탭 여러 개 사이에서 BPM 콘솔을 찾는다. 위 막대 마크가 흐리지 않다. 입력칸이 어디인지 흐린 화면에서도 보인다.
- 어려워지거나 포기하는 것: 마크가 둘이라 둘을 같이 고쳐야 한다 — 기호는 마크의 **가운데 두 도형 그대로**라 마크를 고치면 기호도 같이 본다(§6-1에 적었다). 테두리가 진해져 입력칸이 조금 더 「선」으로 보인다.
- 다시 볼 조건: 정사각 자리가 탭 아이콘 밖으로 늘어나면(앱 아이콘·알림 등) 기호의 쓰임을 다시 적는다.
