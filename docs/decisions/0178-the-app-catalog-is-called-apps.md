# ADR-0178. 「연결 앱」 화면을 「앱」으로 부른다

| 항목 | 값 |
| --- | --- |
| 상태 | 수락 |
| 날짜 | 2026-11-20 |
| 관련 | 화면 CON-18·CON-17·CON-00 [M], [ADR-0138](0138-console-app-catalog.md)(이 화면), [ADR-0149](0149-console-menu-follows-the-work.md)(줄 이름 = 화면 제목) |

## 배경

메뉴 묶음이 「연결」인데 그 아래 줄·화면 제목·단추가 「연결 앱」·「새 연결 앱...」이라 지금 자리가 「연결 › 연결 앱」으로
같은 말을 거듭한다. 사용자가 2026-11-20에 화면 제목과 단추에서 「연결」을 빼자고 했다.

## 선택지

| 선택지 | 장점 | 단점 |
| --- | --- | --- |
| A. **화면 이름을 「앱」으로** — 메뉴 줄·제목·단추·다른 화면의 글이 다 따라간다 | 묶음 이름이 뜻을 이미 말한다. 줄 이름 = 화면 제목(ADR-0149)이 그대로 산다 | 묶음 밖(일꾼 화면)에서는 「앱」만으로 덜 또렷하다 |
| B. 제목·단추만 바꾸고 메뉴 줄은 「연결 앱」 | 메뉴만 보고도 또렷하다 | 줄 이름과 화면 제목이 갈라진다 |

## 결정

**A다.** 사람에게 보이는 글의 「연결 앱」을 「앱」으로 쓴다 — 메뉴 줄, 화면 제목, 「새 앱...」, 일꾼 화면의 「맡을 앱」.
주소(`/connected-apps`)·코드 이름은 그대로다(옛 링크를 깨지 않는다).

## 결과

- 쉬워지는 것: 지금 자리가 「연결 › 앱」으로 읽힌다.
- 어려워지거나 포기하는 것: 「앱」은 서비스 앱·외부 앱을 함께 이르는 넓은 말이다 — 화면의 「구현」 열이 가른다.
- 다시 볼 조건: 「앱」이라는 이름의 다른 화면이 생기면.
