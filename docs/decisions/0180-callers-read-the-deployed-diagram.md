# ADR-0180. 부르는 쪽은 배포된 판의 그림을 Center에서 읽는다

| 항목 | 값 |
| --- | --- |
| 상태 | 수락 |
| 날짜 | 2026-11-20 |
| 관련 | 계약 C5 `diagram`, [ADR-0136](0136-run-detail-shows-the-diagram.md)(이 길을 만들었다), [ADR-0150](0150-the-designer-key-is-gone.md)(패키지 읽기는 콘솔 토큰만), [ADR-0081](0081-answering-on-behalf.md)(대리 답용 키), [ADR-0048](0048-installing-shared-packages.md)(공유 BPM은 패키지의 `libs/`에 든다) |

## 배경

Company1(회사 시스템)은 BPM 그림을 **제 저장소의 사본**(`bpm/`)에서 읽어 왔다 — 업무 처리기는 노드를 찾으려고, 회사
사이트는 시연 화면에 진행 그림을 그리려고. 사용자가 2026-11-20에 **원본은 로컬 Center**이고 그 사본은 쓰지 않는다고
정했다. 그러면 부르는 쪽이 그림을 Center에서 받아야 하는데 지금 길로는 셋이 막힌다.

1. `GET /packages/{id}/{v}/diagram`은 **콘솔 토큰만** 읽는다 — 부르는 쪽이 쥔 것은 연동용·대리 답용 키다.
2. 진입 정의 하나만 준다 — 호출 활동이 부르는 공유 BPM 프로세스의 그림(패키지의 `libs/`)은 받을 길이 없다.
3. 판을 알아야 한다 — 부르는 쪽은 `POST /jobs`에 판을 비우고 Center가 고르게 한다(C5).

## 선택지

| 선택지 | 장점 | 단점 |
| --- | --- | --- |
| A. **`diagram`을 넓힌다** — `?path=`로 패키지 안 `.bpmn`을 고르고, 판 자리 `deployed`는 작업이 돌릴 판, 연동용·대리 답용 키도 읽는다 | 길 하나. 받는 그림이 **실제로 도는 판**과 같다 | 키가 패키지 하나의 그림을 볼 수 있다(목록·정보는 여전히 못 본다) |
| B. 키에 패키지 내려받기(zip)를 연다 | 한 번에 다 받는다 | 매니페스트·메모리까지 나간다. ADR-0150이 닫은 「무엇이 올라와 있나」가 다시 열린다 |
| C. 사본을 스크립트로 맞춘다 | Center를 바꾸지 않는다 | 사본이 남는다 — 요청과 다르다 |

## 결정

**A다.** `GET /packages/{id}/{version}/diagram`이 셋을 받는다.

1. **`?path=`** — 패키지 안의 `.bpmn` 하나(`process/…` 또는 `libs/…`). 비우면 지금처럼 진입 정의다. 공유 BPM 패키지는
   진입이 없으니 `path`를 적어야 한다. 그 밖의 파일(매니페스트·`memory/`·DMN)은 주지 않는다.
2. **판 자리 `deployed`** — `POST /jobs`가 판을 비웠을 때 **고를 판**(어느 서버 실행기에든 활성 배포된 것, 같은 함수)이다.
   없으면 404 `not_deployed`. 응답 머리 **`X-BPM-Version`**이 고른 판을 말한다(받는 쪽이 판마다 기억한다).
3. **권한** — 읽기·관리자에 더해 **연동용 키와 대리 답용 키**도 이 길 하나를 읽는다(회사가 정해진 키면 제 회사 것만).
   그림에는 업무 값이 없다(C5 원칙 6). 목록·정보·노드·내려받기는 그대로 콘솔 토큰만이다.

## 결과

- 쉬워지는 것: 부르는 쪽에 그림 사본이 없어도 된다. 받는 그림이 지금 도는 판과 같아 「사본이 낡았다」가 없다.
- 어려워지거나 포기하는 것: 키 하나로 그 회사의 배포된 그림을 볼 수 있다. Center가 닿지 않으면 그림도 없다.
- 다시 볼 조건: 키 권한을 조일 때(`docs/09-gaps.md` §3-33) — 연동용 키를 BPM 프로세스 단위로 묶게 되면 이 길도 그 범위로.
